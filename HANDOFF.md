# TurBox — актуальный handoff

Обновлено: 31.08.2026.

## Текущее состояние

Основной сценарий сбора туров стабилизирован. Обычный парсер:

- обрабатывает очередь запросов без ручного нажатия Enter между ними;
- сохраняет для каждого запроса цену либо явный итоговый статус;
- не теряет результат, если необязательный график цен по датам не загрузился;
- проверяет найденную цену на заданный пользователем диапазон;
- выводит итоговую сводку и возвращает ненулевой код при технических ошибках.

Конвертер партнёрских ссылок принимает актуальный выход парсера и пропускает строки со служебными статусами.

## Рабочий процесс

1. Настроить группы запросов в `configs/query_generator_config.json`.
2. Запустить `run_query_generator.bat`.
3. Проверить сгенерированный локальный файл `configs/url_generation_config.txt`.
4. Запустить `run_collection_url_generator.bat`.
5. Получить результаты в `collection_urls.txt`.
6. Запустить `run_collection_link_converter.bat` для формирования партнёрских ссылок.

`configs/url_generation_config.txt` является генерируемым пользовательским файлом и не хранится в Git.

## Итоговые состояния обычного парсера

- `PRICE` — цена успешно получена.
- `NO_RESULTS` — туров по запросу нет.
- `PRICE_PARSE_ERROR` — блок результата найден, но цену разобрать не удалось.
- `REQUEST_ERROR` — запрос не удалось корректно выполнить.

Если включён `searchMinPriceData=true`, отсутствие данных в графике дат фиксируется как `CHEAPEST_DATE_UNAVAILABLE`, но основной запрос всё равно завершается и его цена сохраняется.
