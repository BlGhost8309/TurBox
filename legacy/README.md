# Legacy / архив старого конвейера

Эта папка создана на этапе Stage 1 рефакторинга 21.08.2026.

Здесь лежат файлы предыдущего конвейера TurBox, которые **не вызываются четырьмя текущими рабочими BAT-файлами**:

- `collection_parser.py`, `parser.py`, `io_utils.py`, `models.py` — старый парсер подборок;
- `selection_builder.py`, `post_generator.py` и их launch-скрипты — старый конвейер сборки постов;
- `top_hotels_parser.py` — старая Selenium-реализация TopHotels; дальнейшее развитие планируется через HotelIQ Core;
- `_bak`-файлы — ручные резервные копии;
- старые конфиги и результаты.

Ничего здесь не удалено. Папка предназначена как страховка и источник исторической логики. На Stage 1 эти файлы не считаются частью рабочего production-конвейера и не тестируются.
